---

This guide gets you from zero to a running TiKV cluster with working read/write operations. Choose the deployment method that fits your setup.

<Tabs>
  <Tab title="Binary (single node)">
    The fastest way to run TiKV is using pre-built binaries. You need both TiKV and the Placement Driver (PD).

    <Steps>
      <Step title="Download binaries">
        Set your platform and version, then download both binaries:

        ```bash
        export TIKV_VERSION=v7.5.0
        export GOOS=linux   # linux or darwin
        export GOARCH=amd64 # amd64 or arm64

        curl -O https://tiup-mirrors.pingcap.com/tikv-$TIKV_VERSION-$GOOS-$GOARCH.tar.gz
        curl -O https://tiup-mirrors.pingcap.com/pd-$TIKV_VERSION-$GOOS-$GOARCH.tar.gz

        tar -xzf tikv-$TIKV_VERSION-$GOOS-$GOARCH.tar.gz
        tar -xzf pd-$TIKV_VERSION-$GOOS-$GOARCH.tar.gz
        ```
      </Step>

      <Step title="Start PD">
        PD (Placement Driver) manages the cluster metadata and must start before TiKV:

        ```bash
        ./pd-server \
          --name=pd \
          --data-dir=/tmp/pd/data \
          --client-urls="http://127.0.0.1:2379" \
          --peer-urls="http://127.0.0.1:2380" \
          --initial-cluster="pd=http://127.0.0.1:2380" \
          --log-file=/tmp/pd/log/pd.log
        ```
      </Step>

      <Step title="Start TiKV">
        In a new terminal, start the TiKV server pointing at your PD endpoint:

        ```bash
        ./tikv-server \
          --pd-endpoints="127.0.0.1:2379" \
          --addr="127.0.0.1:20160" \
          --data-dir=/tmp/tikv/data \
          --log-file=/tmp/tikv/log/tikv.log
        ```
      </Step>

      <Step title="Verify and connect">
        Check that TiKV is running by querying the status endpoint:

        ```bash
        curl http://127.0.0.1:20180/status
        ```

        Then install the Python client and try your first reads and writes:

        ```bash
        pip3 install -i https://test.pypi.org/simple/ tikv-client
        ```

        ```python
        from tikv_client import RawClient

        client = RawClient.connect(["127.0.0.1:2379"])

        client.put(b'foo', b'bar')
        print(client.get(b'foo'))  # b'bar'

        client.put(b'foo', b'baz')
        print(client.get(b'foo'))  # b'baz'
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="Docker Compose (3-node cluster)">
    Docker Compose spins up a production-like cluster with 3 PD nodes and 3 TiKV nodes. No building required — it uses pre-built nightly images from Docker Hub.

    <Warning>
      On macOS, use `docker compose` (with a space) instead of `docker-compose` (with a hyphen) in all commands.
    </Warning>

    <Steps>
      <Step title="Start the cluster">
        From the root of the TiKV repository (or any directory with the `docker-compose.yml` file):

        ```bash
        docker-compose up -d
        ```

        This starts 6 containers: `tikv-pd1`, `tikv-pd2`, `tikv-pd3`, `tikv-tikv1`, `tikv-tikv2`, `tikv-tikv3`. TiKV nodes wait for all 3 PD nodes to be healthy before starting.
      </Step>

      <Step title="Check cluster status">
        ```bash
        docker-compose ps
        ```

        Once all containers show `healthy`, the cluster is ready.

        You can also verify the PD health endpoint:

        ```bash
        curl http://127.0.0.1:23791/pd/api/v1/health
        ```
      </Step>

      <Step title="Connect to the cluster">
        The cluster exposes these endpoints on localhost:

        | Service | Endpoints |
        |---------|-----------|
        | PD client | `127.0.0.1:23791`, `127.0.0.1:23792`, `127.0.0.1:23793` |
        | TiKV status | `http://localhost:20181/status`, `http://localhost:20182/status`, `http://localhost:20183/status` |

        Install the Python client and connect to any PD endpoint:

        ```bash
        pip3 install -i https://test.pypi.org/simple/ tikv-client
        ```

        ```python
        from tikv_client import RawClient

        # Connect to one or more PD endpoints
        client = RawClient.connect(["127.0.0.1:23791"])

        client.put(b'hello', b'tikv')
        print(client.get(b'hello'))  # b'tikv'
        ```
      </Step>

      <Step title="Stop the cluster">
        ```bash
        # Stop containers (preserves data volumes)
        docker-compose down

        # Stop and remove all data
        docker-compose down -v
        ```
      </Step>
    </Steps>
  </Tab>
</Tabs>
