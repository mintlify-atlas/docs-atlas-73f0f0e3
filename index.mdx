TiKV is a distributed key-value database designed for production workloads at massive scale. Originally created to complement [TiDB](https://github.com/pingcap/tidb), TiKV provides both classic key-value APIs and fully ACID-compliant distributed transactions. It is a graduated project of the [Cloud Native Computing Foundation (CNCF)](https://cncf.io/).

## Key features

<CardGroup cols={2}>
  <Card title="Raft consensus" icon="shield-check" href="/concepts/raft-consensus">
    Strong consistency via Raft with automatic leader election and log replication.
  </Card>
  <Card title="Distributed transactions" icon="arrows-rotate" href="/concepts/mvcc-transactions">
    ACID transactions using the Percolator model with MVCC snapshot isolation.
  </Card>
  <Card title="Horizontal scalability" icon="arrows-left-right" href="/concepts/region-management">
    Auto-sharding via Placement Driver scales to 100+ TBs seamlessly.
  </Card>
  <Card title="Coprocessor" icon="microchip" href="/concepts/coprocessor">
    Push computation to storage nodes to reduce data movement and latency.
  </Card>
</CardGroup>
